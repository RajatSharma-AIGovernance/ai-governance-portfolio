## 🏛️ Module 1: Functional Scope of ISO/IEC 27090:2026
While **[1.1.1 - ISO 42001 Manual](./1.1.1-iso-42001-translation-manual.md)** acts as the organizational framework (AIMS) [2.1], **ISO/IEC 27090:2026** provides the non-certifiable, highly granular technical implementation guidance required to address threats and compromises unique to artificial intelligence systems [2.1]. This manual bridges the gap between conventional information security controls (ISO/IEC 27001/2) and specialized adversarial machine learning vulnerabilities across the system lifecycle.

## 🛡️ Module 2: AI-Specific Technical Security Control Matrix

This matrix establishes the technical safeguards required under Track B pipelines to actively monitor, detect, and mitigate mathematical and business-logic model exploits.

| Control Code | Technical Security Attack Vector | Plain-English Meaning (What it is) | The Enterprise Risk (What breaks) | The Engineering Fix (How to solve) |
| :--- | :--- | :--- | :--- | :--- |
| **SEC-90-01** | **Adversarial Evasion / Input Perturbation** | Attackers making microscopic alterations to non-text inputs (images, audio, logs) that hoodwink the model while remaining invisible to humans. | A rogue actor slightly shifts pixels on an invoice, causing an automated accounting system to misclassify a fraudulent balance. | Implement adversarial training loops during model fine-tuning and apply strict multi-spectral anomaly detection on arrays. |
| **SEC-90-02** | **Model Extraction & Reverse-Engineering** | Subverting public API endpoints through coordinated query bursts to map internal weights and steal the model. | A competitor uses automated scripts to map your custom model’s decision space, copying your custom intellectual property. | Deploy active query pattern analyzers, aggressively rate-limit API keys, and obscure raw confidence score return values. |
| **SEC-90-03** | **Data Poisoning Integrity Exploits** | Malicious injection of tainted coordinates or bad tokens into base fine-tuning training datasets. | An attacker alters historical telemetry pools, embedding permanent blind spots or backdoors within predictive networks. | Enforce dataset cryptographic signature verification and deploy isolated statistical data-cleansing pipelines. |
| **SEC-90-04** | **Prompt-Driven System Escalation** | Direct or indirect prompt injection targeting systemic orchestration frameworks (`LLM01`/`AGE01`) [2.1]. | Malicious data strings break through input fields to commandeer downstream agent workflows, hijacking system authorizations [2.1]. | Hardcode structural prompt isolation layers at runtime and deploy synchronous semantic shield checkers (LlamaGuard) [2.1]. |
